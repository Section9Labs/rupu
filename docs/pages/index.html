rupu package repositories

rupu is an agentic code-development CLI. This site hosts the APT and YUM repositories used to install and update rupu's signed .deb and .rpm packages, along with the public key used to verify them.

Repositories

  • APT: https://section9labs.github.io/rupu/apt
  • YUM: https://section9labs.github.io/rupu/yum/<channel>

Signing key

Packages are signed with the rupu package-signing key. Public key: https://section9labs.github.io/rupu/rupu-archive-keyring.asc

Fingerprint: 6A2918F205000696D657AC61D672DF3BE13ADFDD

Setup instructions live in the rupu repository.
