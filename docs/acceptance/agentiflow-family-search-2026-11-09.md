# Captured Agentiflow family transcript search

Source-only extension of the existing HTTP/MCP `runs.transcript_search` operation at `GET /api/runs/:id/transcripts/search`; new advertised capability `agentiflow.transcript_search.v1`. Existing run-family capability and routes remain unchanged. No execution, provider access or grants are introduced.

A canonical Agentiflow record, exact round-zero RunStart and canonical children ledger establish ownership. Every canonical `lead/transcript.r<N>.jsonl` is a separate searchable transcript under the same Agentiflow run ID; no child IDs are manufactured. Ledger-dispatched agents/workflows and recursively recorded workflow step/child membership use the existing bounded capture. Root Agentiflow `step_results`/legacy-subdirectory inference is not used. Legacy Agentiflows without canonical ownership/ledger evidence remain explicitly unsupported; old unit folders alone are not promoted to authority.

The lead directory is enumerated within the existing 100,000-entry budget and captured transcript count is bounded at 10,000 and metadata at16 MiB. Symlinks, nonregular round files, round aliases/overflow and contradictory tree owners fail closed. Each hit still needs a first RunStart matching exact run and project, without contradictory local-host/top-level aliases. Every full transcript is pinned by its file stamp; direct hit cursors use the flow as authorization root. The root proof hashes its recorded prologue anchor, not the entire lead transcript.

The request retains existing 8 MiB/10,000-record scan, 50-hit,1 MiB response,10-minute capture and64 MiB cache bounds. `members_total` counts captured transcript members (multiple lead rounds can share the same flow ID). Search order is root round zero, captured descendant traversal, then remaining numeric lead rounds. Added rounds/children are outside an existing observation; Search Again recaptures. EOF never upgrades historical completeness from unknown. Remote and unverified/missing transcripts retain explicit coverage counts.

The native existing Find rail uses a separately gated Agentiflow scope when the exact visible reader belongs to a verified current Agentiflow. Embedded unrelated readers cannot inherit that background flow. A recorded lead result is labelled by round and decoded against its exact flow/path; children retain provenance. Results open an exact bounded preview and Back to Results. Open Conversation remains restricted to an already loaded verified native child route, so a search result does not fabricate a new composer destination.

Eight new Rust tests and four new Swift tests are authored but unexecuted. They cover multiple rounds, nested workflow descendants, direct pager cursors, owner/tree/round/path/prologue conflicts, changed captured files, old-server feature refusal and native preview routing. Rust formatting, patch checks and native grid lint are source checks only. No compilation, live API, GUI, provider, thousand-run or performance claim is made. Root must compile/test the exact combined source and perform actual UI acceptance before shipping.
