Configuration

Everything rupu reads from config.toml — every section and key, its type, its default, and what it does. All keys are optional: an empty file (or no file) is a working configuration.

Files and layering

rupu reads up to three TOML files and merges them, most specific last:

LayerFileUse it for
Global~/.rupu/config.tomlYour accounts, defaults, pricing, control-plane settings. RUPU_HOME moves the whole directory.
Customer~/.rupu/customers/<slug>/config.tomlPer-customer overrides for every project assigned to that customer — see Customer layer.
Project<repo>/.rupu/config.tomlRepo-local overrides, checked in with the code.

Scalars and tables from a more specific layer override the less specific one; arrays replace rather than merge (a project that declares [[scm.rules]] replaces the global list). Resolution order, highest first:

# highest wins
global lock  ›  customer lock  ›  project  ›  customer  ›  global  ›  built-in default

Sections are strict: an unknown key inside a section such as [bash], [cp] or [netflow] is a parse error rather than a silently ignored typo. A few retired keys are still accepted as no-ops — see Deprecated keys.

Environment variables

There is no environment layer — environment variables are never merged into the config. A handful are read directly by the code they affect and win over the matching key there:

VariableEffect
RUPU_HOMEMoves the global directory (default ~/.rupu): config, credentials, runs, caches.
RUPU_LOGWins over log_level.
RUPU_MAX_OPEN_FILES, RUPU_MAX_CONCURRENT_JOBS, RUPU_MIN_FREE_MEMORY_MBWin over the [runtime] keys of the same name.
RUPU_NETFLOW_SUBPROCESS=0Forces [netflow].subprocess_capture off.
RUPU_NO_UPDATE_CHECKSuppresses the passive update notice, like [update].check = false, when set to anything other than empty, 0 or false (so RUPU_NO_UPDATE_CHECK=0 leaves it on).
RUPU_LIVE_VIEW=0Turns the workflow live view off (as --plain does).
NO_COLORForces [ui].color = "never".
VISUAL / EDITORUsed when [ui].editor is unset.
RUPU_<ACCOUNT>_API_KEYAPI-key fallback for a provider account with no stored credential — see Providers.

Reading and editing

rupu config get ui.theme
rupu config set cp.gate_sweep_interval_secs 30
rupu config set update.channel beta

rupu config get / set work on the global file only. Dotted keys descend into tables; the value is parsed as a TOML scalar (string, integer or bool), and set refuses to replace a table with a scalar or the reverse. Edit arrays and tables ([[scm.rules]], [recovery].fallbacks) by hand, a customer layer with rupu customer edit <slug>, or everything from the control plane's Settings page, which shows each effective value with the layer it came from, a lock toggle, and a raw TOML editor.

Locks and policy — [policy]

KeyTypeDefaultNotes
lockarray<string>[]Dotted key paths (permission_mode, autoflow.max_active) whose value from this layer can't be overridden. A global lock beats every layer; a customer lock beats the project layer only and cannot unlock a key the global list names. A project's own lock list is ignored.
 
# ~/.rupu/config.toml — no project or customer can loosen these
permission_mode = "readonly"

[policy]
lock = ["permission_mode", "bash.env_allowlist"]
Scope of a lock. A lock covers config keys only. An agent whose own frontmatter names provider: or auth: still runs on that provider even when default_provider is locked.

Customer layer

Assign a project to a customer with rupu customer assign <slug> (a slug is 1–63 of a-z, 0-9, -; none is reserved). The customer's config.toml then sits between the global and project files for every run in that project — and its subdirectories, since a run uses the nearest assigned ancestor of its working directory.

# ~/.rupu/customers/northwind/config.toml
default_provider = "anthropic-northwind"

[[scm.rules]]
owner   = "northwind-labs"
account = "github-northwind"

[policy]
lock = ["default_provider"]   # a repo's .rupu/config.toml can't move these runs
  • Accounts are declared once, globally (rupu auth login --account anthropic-northwind --kind anthropic); the customer layer only references them.
  • A run records the customer it ran under; workflow resume / approve reuse that record even if the project was reassigned since.
  • A dangling assignment or an unparseable customer layer fails the run — it never falls back to global.
  • rupu customer show <slug> prints the effective config with sources and locks.

Model providers — [providers.<account>]

One table per provider account: a bare vendor name (anthropic, openai, gemini, copilot), a named account of a vendor (anthropic-work with kind = "anthropic"), or an openai-compatible endpoint you name yourself. An agent's provider: names the account. Narrative: Providers & Auth.

KeyTypeDefaultNotes
kindstringnone (the table name is the vendor)Vendor of a named account, or openai-compatible. Written for you by rupu auth login --account <name> --kind <vendor>. An unknown kind is a load error.
base_urlstringvendor URLRead by openai-compatible accounts.
default_modelstringnoneBeats the global default_model for agents on this account.
streambooltruefalse forces non-streaming for servers without SSE.
org_idstringnoneOpenAI only; sent as OpenAI-Organization.
regionstringnoneAccepted; not used by any shipped client today.
timeout_msinteger1200000 counts as unset.
max_retriesinteger1Retries after the first attempt on a retryable error.
max_concurrencyintegeranthropic 4, openai 8, gemini 4, copilot 4In-flight requests per account; 0 counts as unset.
prompt_cachebooltrueAnthropic only. false for gateways that reject cache_control; an agent's anthropicPromptCache overrides it.
modelsarray of tables[]Each entry: id (required), context_window and max_output (optional; when unset or 0 the limit is discovered from the provider's model list).
 
[providers.anthropic]
default_model = "claude-sonnet-4-6"
max_concurrency = 6

[providers.lab-llm]              # an OpenAI-compatible endpoint
kind = "openai-compatible"
base_url = "http://10.0.0.20:8000/v1"
default_model = "qwen3-coder"
models = [{ id = "qwen3-coder", context_window = 131072, max_output = 8192 }]

An openai-compatible account must set base_url and default_model, and may not reuse a reserved name (anthropic, openai, gemini, copilot, local, github, gitlab, linear, jira).

SCM and trackers — [scm.*], [[scm.rules]], [issues]

KeyNotes
[scm.default].platformFallback platform when a tool call omits platform. (owner / repo here are deprecated and never read.)
[issues.default].trackerFallback tracker when a tool call omits tracker.
[issues.default].project<owner>/<repo> default for rupu issues list, between an explicit --repo and git-remote autodetection. Needs tracker set too.
[scm.<account>]One table per SCM account ([scm.github], [scm.gh-work]). Keys: kind (github | gitlab; omit when the name is the platform), base_url, timeout_ms (default 30000), max_concurrency (github 8, gitlab 6), clone_protocol (https | ssh, default https), and GitLab-only oauth_client_id — the OAuth application SSO logs in as (glab's on gitlab.com; required for self-managed; read from the global file only).
[[scm.rules]]Account selection when two accounts share a platform. Each entry sets account plus exactly one of owner (repo-owner glob) or path (cwd glob). Precedence: --account → owner rule → path rule → the sole account of that platform → error. rupu scm bind appends one.
 
[scm.github]
clone_protocol = "ssh"

[scm.gh-work]
kind = "github"
base_url = "https://ghe.example.com/api/v3"

[[scm.rules]]
owner = "example-corp/*"
account = "gh-work"

[[scm.rules]]
path = "~/Code/work/*"
account = "gh-work"

See Integrations for the full routing story.

Machine limits — [runtime]

KeyTypeDefaultNotes
max_open_filesintegerunsetSoft open-file limit rupu raises itself to at startup, and the cap for automatic growth under fan-out. Unset: raise to 10240 (capped at the hard limit) and grow on demand. Past the cap, new agent runs are paced instead of failing with "Too many open files". Env: RUPU_MAX_OPEN_FILES / --max-open-files.
max_concurrent_jobsintegerRAM-derivedProcess-wide ceiling on local agent jobs, whatever a workflow's max_parallel: / max_concurrency: says. Unset: clamp(RAM_GB / 4, 4, 128). 0 means no ceiling. Remote (distribute:) units are bounded by their own host. Env: RUPU_MAX_CONCURRENT_JOBS.
min_free_memory_mbintegerRAM-derivedMemory watchdog: a new local job waits until this much memory is free (proceeding anyway after 60 s, with a warning). Unset: max(RAM × 10%, 4096). 0 disables the watchdog. Env: RUPU_MIN_FREE_MEMORY_MB.

Control plane — [cp]

Background loops rupu cp serve runs in-process, so autoflows, triggers and gate timeouts work with no external cron.

The loop toggles and intervals below, like agentiflow.reaper_enabled and netflow.asn_auto_refresh, are read once when cp serve starts: change them and restart it. Saving the global config from the control plane lists the ones you changed as restart_required; every other key applies at once.

KeyTypeDefaultNotes
max_workspace_bytesinteger256 MiBLargest workspace-sync payload or delta for placed runs.
autoflow_reconcile_enabledbooltrueRun the autoflow reconcile loop (issue/PR entity autoflows).
autoflow_reconcile_interval_secsinteger60
cron_tick_enabledbooltrueRun the cron / polled-event trigger tick (what rupu cron tick does).
cron_tick_interval_secsinteger60
gate_sweep_enabledbooltrueEnforce gate on_timeout routing and reap orphaned runs whose runner process died. The same tick also drives the ASN refresh and the agentiflow reaper, each gated by its own key.
gate_sweep_interval_secsinteger60
Retired UI flags. agent_authoring_ui and workflow_editor_ui are no longer read: the agent builder and workflow editor are the only UIs. They still parse (with a warning) so an old config keeps loading — delete them.

Pricing — [pricing]

Turns token counts into USD for rupu usage, run listings and the control plane. Lookup order: [pricing.<provider>."<model>"] override → built-in table (each vendor's standard-tier list rate) → [pricing.agents.<agent>]. A named account prices through its kind, and an account-level override beats the vendor one. Model ids match exactly, then with a trailing [tag] stripped, then with a date snapshot stripped.

FieldTypeRequiredNotes
input_per_mtokfloatyesUSD per million input tokens.
output_per_mtokfloatyesUSD per million output tokens (reasoning tokens included).
cached_input_per_mtokfloatnoCache reads; defaults to the input rate.
cache_write_per_mtokfloatnoCache writes; defaults to the input rate.
 
[pricing.anthropic."claude-sonnet-4-6"]
input_per_mtok = 3.0
output_per_mtok = 15.0
cached_input_per_mtok = 0.30
cache_write_per_mtok = 3.75

[pricing.lab-llm."qwen3-coder"]    # an openai-compatible account
input_per_mtok = 0.4
output_per_mtok = 1.2

[pricing.agents.triage-bot]        # fallback when no model price is known
input_per_mtok = 0.5
output_per_mtok = 1.5
