One visual language for the Control Plane
The same eight components, used the same way on every screen. Below: each fix shown as a real, built fragment from the CP's own dark palette — then the language spelled out. Nothing here invents new colors; it removes the inconsistencies.
01

Page header

3 different headers (ghost "Refresh" · filled-purple "Save changes" · "Spend →")→one header, one action hierarchy

Every page opens the same way: an optional Back, a title at one size, an optional one-line subtitle, and a right-aligned action zone. The primary action is near-white and solid; everything else is a bordered secondary or a ghost icon. The brand purple never becomes a chrome button — it stays on data and identity.

02

Chips & status

blue "global" pills · bare status dots · severity words · colored text→one chip shape, tint + colored text

One pill: a pale tint of its own hue with dark-on-light text, a dot only for live status. Status (running/ok/failed), severity (high/med/low), and config origin (global/project) all share the shape — so a screen never mixes four pill styles.

03

KPIs & charts

6 bordered tiles, a sparkline on one, gradient area fills→one divided strip, type-first; flat 2px lines

KPIs are type, not tiles: one panel divided by hairlines, label over number, the one that needs attention in red. No sparkline on a KPI — the trend gets its own flat chart with 3 faint gridlines, a 2px line, no gradient, one hue.

Form fields

The language, spelled out

Type scale
Page title 19–24px/600 · section 15px/600 · body 13px · label/meta 11–12px. Two sizes do the work; nothing between.
Numbers
Always tabular, right-set in columns, thousands separators, a unit in grey.
Color
On data and status only. Brand purple = identity + the one accent, never a chrome button. Grey for what's fine; red/amber only for what needs attention.
Buttons
One primary (near-white solid) per view, secondary bordered, ghost for icons. Destructive is bordered red.
Surfaces
Separated by a tone step or one hairline, never both, never a shadow at rest. Radius 8–12, chosen once.
Chips
One pill shape for status, severity and origin — pale tint, colored text, a dot only for live status.
Loading & empty
A skeleton in the real layout, then an empty state that keeps the frame and says one plain sentence.
Microcopy
Sentence case, plain words, every relative figure names its baseline (“+4 vs prior 30d”, not a bare “+4”).
