# Agentiflow per-call usage pages v1

Base a42e3beaa5736998fabcf9513976545044e326de. Capability `agentiflow.usage.pages.v1` on Unix. Legacy usage-timeline is unchanged.

GET `/api/agentiflows/:id/usage-timeline/page?host=local&project=ws_id&limit=100` captures one finite observation. Subsequent requests send the same exact `snapshot` and optional opaque `cursor`; omit cursor to revisit Start within the same observation. Omit both for explicit Refresh. Project is mandatory and must equal the exact canonical flow's round-zero RunStart workspace. No selected-project inference, remote forwarding or whole-ledger legacy fallback. Unknown fields reject.

The first request reads canonical agentiflow.json (256KiB), only round-zero lead's first record (256KiB), usage.jsonl (16MiB) and children.jsonl (8MiB). Each opened source is reopened through anchored descriptors, its file identity rechecked and its exact captured prefix compared before publication; appends beyond the captured EOF remain excluded. Ledger capture plus prefix verification reads at most48MiB, with bounded proof verification additional. These checks detect observed replacement/rewrite and are not a filesystem transaction against arbitrary concurrent writers. It never opens paths in ledger rows, walks descendants, scans project catalogs or reads whole transcripts. Each capture admits at most 100,000 physical ledger lines combined and 64KiB per line. Exceeding any bound rejects413, never an undisclosed first-N prefix. One nonqueued capture per AppState; contention429. Captured serialized rows are bounded32MiB; cache max64MiB serialized rows/100,000 accepted rows/four observations, 10minute TTL. One capture may temporarily coexist with the bounded cache. These are per owning CP AppState; independent CP processes have independent budgets. IO/parse loops check a five-second cooperative deadline, not a hard deadline on filesystem syscalls.

Envelope (all fields present): schema_version:1; flow_id/project_id/host_id strings; host_id local; owner_instance_id string digest of canonical global-directory identity; snapshot opaque string <=64; source_generation content hash; captured_at/expires_at RFC3339; offset zero-based index; total accepted unique calls; records array; next_cursor string or null; evidence object. owner_instance_id is first-capture evidence bound to this transport/snapshot, not a host-info field; native retains it and requires equality for continuation. Source_generation includes exact captured record/prologue/ledger bytes; no coordinator-atomicity or eternal source-identity claim.

Each record has ledger_id:string (unique within observation), source_line:one-based physical usage-ledger line, ordinal:one-based displayed call ordinal, kind:turn|compaction, at:RFC3339, agent_run_id:string, parent_agent_run_id:string|null, agent/provider/model:string, step_id:string|null, unit_index:unsigned|null, unit_key:string|null, rollup:bool, input_tokens/output_tokens/cached_tokens/cache_write_tokens:unsigned, transcript_path:string, transcript_turn:unsigned|null, round:unsigned|null, round_source:lead_path|unit_catalog|parent_attribution|temporal_fallback|unknown, cost_usd:null. No raw tool input/output is returned. transcript_turn is the deduplicated ledger turn ordinal in file order within that exact transcript; it is an accounting approximation, not a transcript record/page cursor. Compaction has no transcript turn.

Rows sort by (recorded at, physical source_line). Identical repeated ledger IDs count once; conflicting repeated IDs reject409. Ordinals are assigned after deduplication. Exact canonical lead path plus matching flow ID/no parent gives lead_path. Unique recorded child run/round tags give unit_catalog; unique parent's tag gives parent_attribution. Otherwise latest prior lead call in timestamp order gives temporal_fallback; absent evidence gives unknown/null, never invented round0. Any contradictory child round tags remove that run's mapping. All attribution is accounting context only; no row grants ancestry. Ledger parent IDs and paths are untrusted navigation hints. Native can open only a separate verified catalog/prologue route, and otherwise shows readable accounting without an Open action.

Evidence fields: usage_ledger_present:boolean, children_ledger_present:boolean, usage_bytes:unsigned, children_bytes:unsigned, source_lines:unsigned, malformed_rows:unsigned, unsupported_rows:unsigned, duplicate_rows:unsigned, incomplete_tail_count:unsigned, ambiguous_round_runs:unsigned, source_complete:boolean, consistency:"captured_read_time_observation", navigation:"requires_independent_catalog_and_prologue". Source_complete=false when malformed/unsupported/incomplete input was omitted; duplicates count once and ambiguity remains explicitly reported. A missing usage ledger is unavailable evidence (false/source_complete=false), not proof of zero total historical spend. Project proof is required even for empty pages. Appends after the captured EOF do not appear until Refresh. No global usage totals or cost estimate is fabricated.

Page limit1..100, response<=1MiB. next_cursor=null means no more accepted rows in this observation, not a statement of complete runtime accounting. Cursor HMAC binds exact snapshot/flow/project/local owner and position, no time cursor. Expired/evicted/restarted/foreign snapshot409; forged/wrong-scope cursor409; malformed syntax400; bound/deadline413; busy429; unavailable first proof501; owner disagreement409; missing flow404; IO500; explicit remote501. Errors use existing `{error:string}`. Keep prior pages visible and offer explicit Refresh on expiry; never convert errors into an empty successful series.

Read-only HTTP and MCP parity: `agentiflows.usage_timeline_page`. No model execution, writes, services or live requests are part of implementation validation.
